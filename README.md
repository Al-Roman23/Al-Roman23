## 🚀 Featured Projects

### Real-Time Emergency Dispatch Platform (NeoSaver)

**Java 21 • Spring Boot • PostgreSQL • Redis • WebSockets • Flyway • JWT • AWS • Terraform • Docker**

Production backend for an ambulance dispatch platform with real-time driver discovery, fare negotiation, GPS tracking and OTP-verified trips. The code is private.

- Designed and built a modular Spring Boot architecture from the ground up.
- Implemented STOMP over WebSockets for live bidding, trip-state sync, GPS tracking and notifications, plus Firebase push.
- Designed the PostgreSQL data model with versioned Flyway migrations.
- Implemented JWT with role-based access control, OTP verification and Redis for caching, sessions and rate limiting.
- Built driver commissions, wallets and FIFO payment settlement.
- Runs on AWS (EC2, VPC, RDS, ElastiCache, S3, ECR) behind Caddy, with the whole account built in Terraform and GitHub Actions deploys that roll back automatically if the health check fails.

### 1550+ SAT Prep Platform

**Next.js • TypeScript • Bun • Hono • PostgreSQL • Drizzle ORM • Redis • BullMQ**

Live learning platform for a US SAT-prep, college admissions and scholarships company, from the first diagnostic test to the final score. ([live site](https://1550-plus.com/))

- Designed and built a new diagnostic creation flow: admins add SAT questions to a question bank, then build a diagnostic in six steps (test details, modules, questions, scoring, delivery and review).
- Tested features by hand across the admin panel and student flows, and shipped fixes and enhancements.

### NovaPay Transaction Processing Backend

**TypeScript • Hono • PostgreSQL • Prisma • Redis • BullMQ • Nginx • Docker Compose • GitHub Actions**

Microservice backend for bulk payroll and international transfers, built around idempotent requests and a double-entry ledger. ([repo](https://github.com/Al-Roman23/novapay-backend))

- Built six TypeScript services behind an Nginx gateway, each with its own PostgreSQL database.
- Implemented idempotency keys matched against a payload hash, with a unique index to block concurrent duplicates.
- Designed a double-entry ledger with a balance check and a SHA-256 hash chain to detect tampering.
- Built bulk payroll processing on BullMQ with per-item checkpoints so a crashed job resumes where it stopped.
