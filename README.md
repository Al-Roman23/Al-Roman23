## 🚀 Featured Projects

### Real-Time Emergency Dispatch Platform

**Java 21 • Spring Boot • PostgreSQL • Redis • WebSockets • Flyway • JWT • AWS • Docker**

Production-grade ambulance dispatch platform with real-time driver discovery, fare negotiation, GPS tracking, and OTP-verified trip workflows. ([repo](https://github.com/Al-Roman23/neosaver-backend))

- Designed and developed the backend using a modular Spring Boot architecture.
- Implemented STOMP WebSockets for live bidding, trip state synchronization, GPS tracking, and real-time notifications.
- Designed the PostgreSQL data model with versioned Flyway migrations.
- Implemented JWT/RBAC, OTP verification, Redis caching, sessions, and rate limiting.
- Built driver financial workflows including commission tracking, wallet management, and FIFO payment settlement.
- Deployed the production backend on AWS EC2, RDS, ElastiCache, and S3 using Docker and Nginx.

### NovaPay Transaction Processing Backend

**TypeScript • Hono • PostgreSQL • Prisma • Redis • BullMQ • Nginx • Docker Compose • GitHub Actions**

Microservice backend for bulk payroll and international transfers, built around idempotent requests and a double-entry ledger. ([repo](https://github.com/Al-Roman23/novapay-backend))

- Built six TypeScript services behind an Nginx gateway, each with its own PostgreSQL database.
- Implemented idempotency keys matched against a payload hash, with a unique index to block concurrent duplicates.
- Designed a double-entry ledger with a balance-invariant check and a SHA-256 hash chain to detect tampering.
- Built bulk payroll processing on BullMQ with per-item checkpoints so a crashed job resumes where it stopped.
